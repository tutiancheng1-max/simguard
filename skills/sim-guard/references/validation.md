# 怎样才算独立校验

判断标准：**如果模型里有一个设置错误，这个校验会不会一起错？** 如果会，它就不独立。

| `validation.kind` | 例子 |
|---|---|
| `analytic_limit` | 把模型退化到有解析解的极限，比如一维扩散、平面波反射 |
| `conservation` | 能量或电荷闭合：吸收、储存和流出的量对得上 |
| `independent_method` | 另一种方法或另一个求解器；不共用材料、边界设置和驱动代码 |
| `literature_reproduction` | 复现已发表的图或数，并核对公式和原文的图是否一致 |
| `experiment` | 已发表或自己测量的实验数据 |

## 不算独立的

- 和自己的旧结果一致。旧结果可能带着同一个错误，一致只能说明是“回归测试”。
- 2D 和 3D 一致，但它们来自同一段设置代码。
- 把模型调到和目标数值吻合后，再用同一数值当校验。
- 只看网格收敛。它说明数值解稳定，不说明物理设置正确。

回归测试可以做，也有用，但不能写进 `gate.json` 的 `validation`。

## 校验也要能失败

设计校验时，想一个已知的错误，确认校验会报警。例如，故意把一个张量分量改错，确认能量闭合或解析极限检查会失败。如果报不出来，就换一个校验。

收敛检查也一样。如果离散格式对这个解本来就是精确的，比如二阶差分算二次解，各网格结果会完全相同，这样的“收敛”什么也没证明。换一个不精确的解，或者如实写 `NA` 并说明原因。
